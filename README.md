# CHICKEN DRAW

2〜4人で対戦する心理戦カードゲーム。ホストは開始前に1〜3ラウンドを設定します。

## 現行ルール
- 各ラウンドは1人2ターン。最初に相手を指名し、そのターンは同じ相手から引きます。最低1枚、枚数制限なし。
- 初期手札は数字7枚とドクロ2枚。ドクロは交換不可、配置変更は可能。
- 数字カードは本当の数字で加点。50点以上で上がりますが、50〜60点の実得点は保持します。61点以上はExtra、そのラウンドの最下位（0点・ラウンドボーナスなし）。倍化・ガード後の実際の獲得点で判定します。
- ドクロはバースト。ラウンド得点0になり、そのラウンドの手番・ドロー先・アイテム対象から除外します。
- ドクロガードは1回防ぐ代わりに、そのターンの獲得点を発動前後とも半減。前ターンの点は維持し、0.5点も保持します。
- 初期アイテムは毎ラウンド2個、実際の手番開始時に追加1個。スキップ時は配布なし。
- リバース・ドロー指名アイテムは廃止。ドクロ設置とカード複製は通常アイテムの1/4の出現比率。
- 終了トラップを引くと得点処理後にターン終了。複製でドクロを通常カードに変えることは禁止。
- 偽装カードは偽数字で表示。本当の数字は所有者の吹き出しで確認。透視でも偽装されていれば偽数字が見えます。
- 単独生存者2PT、最高得点者全員1PT（Extra除外）。試合順位はPT、総取得枚数、累計獲得点の順。同条件は同順位。

## 画面と観戦
- 卓は1:1固定。スマホは卓＋縦型操作パネルに切り替え、大きめの手札列を横スクロールして選べます。
- カードのホバー位置を他の参加者と共有。確定選択とは別に発光します。
- 効果音は0〜100%で調節でき、端末に設定を保存。最初のクリックまたはキー操作から有効。
- 結果は全画面表示後にロビーへ復帰。ホストは結果画面のボタンでも戻れます。
- 途中参加者は観戦。手札・所持アイテムなどの非公開情報は配信しません。次試合は空席またはAI席から参加。4人の人間で満員なら参加待ちです。
- 観戦は最大30人。観戦者にはゲーム操作権限を与えません。

## 開発と検証
React / Vinext / Cloudflare Workers / D1。npm run dev、npm run build。
ルール・配置・複数クライアント通信を node --test tests/*.test.mjs で検証。
ゲーム状態は約1秒、ホバーは約120ms間隔で同期。card_hoverは初回アクセス時に自動作成。
公開先は既存サイトがNOT_FOUND、サイト一覧も空のため未公開。ローカル版で動作を提供しています。

## Cloudflare Workers + D1 公開手順

1. Cloudflare Dashboardでアカウントを作成し、Workers & Pagesを有効化する。
2. Node.js 22以上を用意し、プロジェクトで `npm install` を実行する。
3. `npx wrangler login` でCloudflareにログインし、`npm run deploy:check` でログイン状態を確認する。
4. `npx wrangler d1 create chicken-draw-db` を実行し、表示されたDatabase IDを `wrangler.toml` の `database_id` に貼り付ける。`database_name` は変更しない。
5. `npm run build` を実行する。
6. `npx wrangler d1 migrations apply chicken-draw-db --remote` で本番D1を初期化する。
7. `npx wrangler deploy` を実行する。表示された `https://chicken-draw.<アカウント名>.workers.dev` が共有用URLになる。

更新時は `npm run build`、`npx wrangler d1 migrations apply chicken-draw-db --remote`、`npx wrangler deploy` の順に実行する。ローカルは従来どおり `npm run dev` で動作し、本番D1とは分離される。複数端末で同じURLを開いて同じ6桁ルームコードに参加すると、D1上のルーム状態を共有して対戦できる。

本番確認は、URLをPCとスマートフォンで開き、片方でルーム作成、もう片方で同じコードに参加し、指名・ドロー・ラウンド結果が両方に反映されることを確認する。エラー時は `npx wrangler tail chicken-draw` でWorkerログを確認し、D1エラーならDatabase IDとマイグレーション適用先が一致しているかを確認する。
